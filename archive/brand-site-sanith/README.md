# Pace & Publish: brand website

MK-680, Week 10 · Sanith Chandula · A student project for a fictional brand at Sacred Heart University.

**To open it:** double-click `index.html`. It's plain HTML, CSS and JavaScript, with no installs, no server and no build step. Fonts load from Google Fonts when online; everything else is in this folder.

| Page | File |
|---|---|
| Home | `index.html` |
| Race weekend planner (the tool) | `planner.html` |
| Race calendar | `calendar.html` |
| News | `news.html` |
| About | `about.html` |

- `prd.md`: the PRD the site was built from.
- `build-notes.md`: what changed from the PRD and why, where the facts come from, and the SAMPLE data to replace.
- Data lives in `data/` as JavaScript files. The race weekends in `data/sessions.js` are SAMPLE data and are labeled "SAMPLE" on screen.
